# Contributing to Gyan Chaupar

Thank you for your interest in contributing to **Gyan Chaupar (Moksha Patam)**!

This project is dedicated to cultural preservation, mathematical balance, and aesthetic excellence in digital tabletop gaming.

---

## How to Contribute

### 1. Reporting Bugs & Issues
- Open an Issue describing the bug clearly.
- Include your Android OS version, device model, or browser if testing the 3D Web edition.
- Provide step-by-step reproduction instructions or screenshots.

### 2. Suggesting Board Variations & Historical Rules
Gyan Chaupar has rich historical variants across Jain, Rajasthani, Nepalese, and Sufi traditions (84 squares, 100 squares, 128 squares).
- If you have access to archival manuscripts or regional rule sheets, open a Discussion or Issue referencing historical sources.

### 3. Code & Asset Contributions
1. Fork the repository.
2. Create a topic branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Commit your changes with clear, descriptive commit messages.
4. Push to your fork and submit a Pull Request.

---

## Code of Conduct
Please maintain a respectful, welcoming, and constructive environment.
